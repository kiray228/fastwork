# Как запустить fastwork на Windows

Два пути. **Начни с первого** — он занимает минут двадцать. Второй нужен,
когда захочешь увидеть приложение на настоящем телефоне.

---

## Путь 1. Быстрый — запуск в браузере Chrome

Android Studio не нужна. Нужны только Git, Flutter и Chrome.

### Шаг 1. Установить Git

Скачать и установить: https://git-scm.com/download/win
Все галочки оставить по умолчанию, жать «Next».

### Шаг 2. Установить Flutter

1. Скачать архив: https://docs.flutter.dev/get-started/install/windows
2. Распаковать в **`C:\src\flutter`**

> **Важно:** не распаковывай в `C:\Program Files\` — в этом пути есть пробел
> и права администратора, Flutter из-за этого ломается.

### Шаг 3. Прописать Flutter в PATH

PATH — список папок, где Windows ищет программы. Без этого команда
`flutter` не заработает.

1. Нажать «Пуск», набрать `переменные среды`
2. Открыть «Изменение системных переменных среды»
3. Кнопка «Переменные среды…»
4. В верхнем списке («Переменные среды пользователя») выбрать `Path` → «Изменить»
5. «Создать» → вписать `C:\src\flutter\bin` → ОК во всех окнах
6. **Закрыть все окна терминала и открыть заново** — иначе изменения не подхватятся

### Шаг 4. Проверить

Открыть PowerShell (Пуск → набрать `powershell`) и выполнить:

```powershell
flutter --version
```

Если вывелась версия — всё получилось.

### Шаг 5. Скачать проект

```powershell
cd ~
git clone -b claude/brave-albattani-ahueqx https://github.com/kiray228/fastwork.git
cd fastwork
```

### Шаг 6. Запустить

```powershell
flutter pub get
flutter run -d chrome
```

Откроется Chrome с приложением.

> **Горячая перезагрузка.** Пока приложение запущено, измени что-нибудь в
> `lib/main.dart`, сохрани — и нажми `r` в терминале. Изменения появятся за
> секунду, без перезапуска. Это самое приятное в разработке на Flutter.
> `R` (заглавная) — полный перезапуск, `q` — выход.

## Путь 2. Настоящий телефон или эмулятор

Нужен, когда захочется увидеть приложение как приложение.

### Вариант А — свой телефон Android (проще)

1. На телефоне: «Настройки» → «О телефоне» → **7 раз** нажать на «Номер сборки».
   Появится сообщение «Вы стали разработчиком».
2. «Настройки» → «Для разработчиков» → включить **«Отладка по USB»**
3. Подключить телефон к компьютеру кабелем, на телефоне разрешить отладку
4. Установить Android Studio: https://developer.android.com/studio
   (нужна ради Android SDK, саму программу открывать не обязательно)
5. В PowerShell:

```powershell
flutter doctor --android-licenses
flutter devices
flutter run
```

### Вариант Б — эмулятор

1. Открыть Android Studio → «More Actions» → **«Virtual Device Manager»**
2. «Create Device» → выбрать любой телефон → скачать образ системы → «Finish»
3. Запустить эмулятор кнопкой ▶
4. В PowerShell: `flutter run`

> Эмулятор требователен к железу. Если компьютер слабый — используй телефон.

## Если что-то не работает

Выполни:

```powershell
flutter doctor
```

Команда сама расскажет, чего не хватает. Скопируй её вывод в чат — разберём.

---

## Частые ошибки

| Ошибка | Причина и решение |
|---|---|
| `flutter: команда не найдена` | PATH не прописан или терминал не перезапущен после шага 3 |
| `Unable to locate Android SDK` | Не установлена Android Studio. Для пути 1 это не мешает |
| `No devices found` | Не запущен эмулятор / телефон не подключен или не разрешил отладку |
| Ошибки после `git pull` | Выполни `flutter pub get` — появились новые зависимости |
